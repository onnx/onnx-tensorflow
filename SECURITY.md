# Security policy

## Supported versions

No versions of ONNX-TF are currently supported. The final release, 1.10.0,
was published in March 2022 and does not receive compatibility updates, bug
fixes, or security fixes.

| Version | Supported |
| --- | --- |
| 1.10.0 and earlier | No |

Do not use this project for security-sensitive or production workloads without
performing your own risk assessment and maintaining the required fixes in a
fork.

## Reporting a vulnerability

Because the project is archived and unsupported, maintainers cannot commit to
investigating or remediating new reports. If a report concerns the wider ONNX
ecosystem rather than this archived converter, follow the reporting policy in
the [ONNX repository](https://github.com/onnx/onnx/security/policy).
