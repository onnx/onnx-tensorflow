# Contributing

ONNX-TF is no longer maintained and this repository is being archived. New
features, bug fixes, compatibility updates, and pull requests are not being
accepted.

The source and history remain available for reference and may be forked under
the terms of the Apache License 2.0. For maintained ONNX projects and community
participation, visit the [ONNX organization](https://github.com/onnx).
